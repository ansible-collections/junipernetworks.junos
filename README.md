# Juniper Networks Junos Collection — Repository Archived

**This repository has been archived.**

The **junipernetworks.junos** Ansible collection has moved to the consolidated Juniper repository.

## New location

- **GitHub:** [Juniper/ansible-junos-stdlib](https://github.com/Juniper/ansible-junos-stdlib) (collection path: `ansible_collections/junipernetworks/junos/`)
- **Releases:** [Juniper/ansible-junos-stdlib/releases](https://github.com/Juniper/ansible-junos-stdlib/releases)
- **Install from Galaxy:** `ansible-galaxy collection install junipernetworks.junos` (unchanged)
- **Install from Automation Hub:** same namespace and collection name

The collection is still published as **junipernetworks.junos** on [Ansible Galaxy](https://galaxy.ansible.com/junipernetworks/junos) and [Red Hat Automation Hub](https://console.redhat.com/ansible/automation-hub); only the source repository has changed.

For the latest code, issues, and pull requests, use the new repository: **[https://github.com/Juniper/ansible-junos-stdlib](https://github.com/Juniper/ansible-junos-stdlib)*
